# 本地 OLED、按键与菜单

当前固件采用本地直运行界面。OLED 和按键不再作为 CAN/I2C 状态页的附属功能，而是直接拥有 SmartKnob 的模式选择与常用参数配置。

## OLED 与刷新

- 控制器：SSD1306，64×48。
- 接口：软件 4-wire SPI。
- U8g2 配置：`u8g2_Setup_ssd1306_64x48_er_f()`、`U8G2_R2`。
- 驱动：`MyFile/src/oled_u8g2.c`。
- 本地界面：`MyFile/src/local_ui.c`。
- MaintenanceTask 每 10 ms 调用一次 `LocalUiTask()`；OLED 帧率限制为 20 Hz，避免软件 SPI 占用过多 CPU。

原 `u8g2_disp_fun.c` 仍保留 logo、旧协议页面和维护函数，便于回溯，但正常运行不再进入旧四页状态界面和上电阻塞菜单。

## 仪表盘

正常运行时显示一个圆形速度表：

- 指针：轴的有符号角速度，显示范围约为 -24～+24 rad/s，超出后限幅。
- 中央数字：当前 SmartKnob 挡位位置。
- 顶部短标识：当前触感预设，例如 `C+`、`FDET`、`MAG`。
- `PAUSED`：用户双击关闭力反馈。
- `OVER VOLT`、`STALLED`、`FAULT`：保护状态覆盖提示。

表盘只负责显示；18.67 kHz FOC 和 1 kHz SmartKnob 控制不在 OLED 任务中运行。

## 按键事件

按键为 PC6、低电平有效、内部上拉。`button_update()` 使用非阻塞状态机：

| 事件 | 判定 |
| --- | --- |
| 单击 | 按下至少 30 ms，350 ms 内没有第二次点击后上报；本地 UI 当前不使用 |
| 双击 | 两次短按释放间隔不超过 350 ms |
| 长按 | 持续按下 1.2 s 时立即上报，不必等待释放 |
| 超长按兼容事件 | 持续 5 s；仅为旧代码保留 |

20 ms 去抖不会阻塞 MaintenanceTask，也不会像旧实现那样在一次扫描中连续读取 GPIO 数百次。

## 交互逻辑

正常仪表盘：

- 双击：在力反馈运行与 `PAUSED` 之间切换。
- 长按：进入本地菜单；发生保护错误时拒绝进入。

菜单：

- 旋转一个机械挡位：上/下一项，或参数增/减一级。
- 双击：进入当前项，或确认当前值并返回根菜单。
- 参数页长按：取消本项修改并返回根菜单。
- 根菜单长按：保存全部设置并退出。
- 选中 `SAVE` 后双击：保存全部设置并退出。

进入菜单时，ControlTask 将 SmartKnob 切到私有模式 `0xFF`。该模式是 12°、双向无边界的导航挡位，不计入 12 个用户预设，也不会修改用户预设的运行位置。退出菜单后恢复用户选择的预设。

## 菜单项

| 项目 | 范围 | 步进 | 含义 |
| --- | ---: | ---: | --- |
| `MODE` | 12 个内置预设 | 1 个预设 | Custom、Free、Bound、Multi、On/Off、Center、Fine、Fine Detents、Coarse+/−、Magnetic、Center Detents |
| `FORCE` | 25～125% | 5% | 相对预设默认 `current_scale_a` 的力度比例 |
| `STEP` | 1～60° | 1° | 每个挡位的机械角宽度；切换模式时先载入该模式默认值 |
| `LIMIT` | 100～450 mA | 50 mA | SmartKnob 相电流软件上限，仍受底层硬限制约束 |
| `SAVE` | - | - | 写入 Flash 并退出 |

参数编辑期间继续使用独立导航挡位；新触感配置在退出菜单后一次性应用。

## 任务与安全边界

MaintenanceTask 只做按键识别、菜单状态机、OLED 绘图和控制命令投递。以下动作只在 1 kHz ControlTask 中执行：

- 进入/退出导航挡位。
- 切换用户预设。
- 应用力度、挡位角和电流上限。
- 启用/关闭电机输出。

保存退出时先清零电流并关闭驱动，StorageTask 擦写 Flash 后再恢复原来的运行/暂停状态。这样 Flash 停顿不会发生在电机带力输出时。

## RGB

本地状态灯由 `MyFile/src/local_rgb.c` 单独管理，两颗 SK6812/WS2812 始终同步，避免形成无意义的左右乱闪：

| 状态 | 灯效 |
| --- | --- |
| 正常力反馈 | 3.2 s 周期的低亮紫色平滑呼吸 |
| `PAUSED` | 低亮蓝色常亮 |
| 根菜单 | 青色常亮 |
| 参数编辑 | 琥珀色常亮 |
| 正在保存 | 绿色常亮至少 700 ms |
| 故障 | 1.2 s 周期的红色双闪 |

旧 `ws2812_flash()` 不再进入本地运行路径。新驱动只在目标颜色实际变化时请求发送，DMA 正在传输时不会被强制中止；完成回调负责释放发送状态，超过 5 ms 未收到回调才执行一次恢复。正常两像素帧小于 0.1 ms，因此 `ws2812_recovery_count` 和 `ws2812_start_error_count` 在正常运行中应保持为 0。
